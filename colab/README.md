# Setup do Google Colab

O arquivo `Colab_Antigravity.ipynb` contém o código pronto para importar no Google Colab.
Basta fazer o upload deste arquivo para o Colab, ou criar um novo notebook e copiar/colar as células dele.

Lembre-se de substituir a variável `REPO_URL` com a URL do seu GitHub após exportar o projeto!
